# Process Management

여러 서버에 SSH 로 접속해 등록한 프로세스가 실행 중인지 확인하고, 로그를 보고, 시작 · 중지 · 재시작하는 관리 화면입니다.
서버는 직접 만든 그룹(의왕, 광명 ...)으로 묶어서 보여줍니다.

## 사용 방법

- **그룹 이동**: 상단 탭이나 주소로 그룹을 고릅니다. `/all` 은 전체, `/uw` 처럼 그룹 slug 를 쓰면 그 그룹만 보입니다.
- **상태 확인**: 몇 초마다 각 서버에서 `ps` 를 실행해 프로세스별 PID · CPU · MEM · 실행 시간을 보여줍니다. 초록은 모두 실행 중, 주황은 일부 중지, 빨강은 모두 중지되었거나 SSH 접속에 실패한 서버입니다. 왼쪽 사이드바에서 서버를 누르면 해당 카드로 이동합니다.
- **로그**: `로그` 를 누르면 로그 파일의 마지막 줄들을 봅니다. 줄 수를 바꾸거나, 단어로 거르거나, 3초 자동 새로고침을 켤 수 있습니다.
- **시작 · 중지 · 재시작**: 중지는 찾은 PID 에 SIGTERM 을 보내고 종료될 때까지 최대 10초 기다립니다. 시작은 등록한 시작 스크립트를 실행합니다. 재시작은 중지 후 시작입니다.
- **검색**: 서버 이름 · 호스트 · 프로세스 이름으로 카드를 거릅니다.
- **설정**: `⚙ 설정` 에서 그룹 · 서버 · 프로세스를 추가 · 수정 · 삭제하고 저장하면 바로 반영됩니다. **내보내기**로 설정 파일을 받고(비밀번호 제외), **가져오기**로 다시 불러올 수 있습니다.

## 설정 항목

| 구분 | 항목 | 설명 |
|---|---|---|
| 그룹 | slug · 이름 | slug 는 주소(`/uw`)로 쓰는 영문 소문자 · 숫자 · `-`. `all`, `api`, `config`, `static` 은 쓸 수 없습니다 |
| 서버 | host · port · user · 비밀번호 | SSH 접속 정보 (port 기본 22). 비밀번호는 서버 파일에만 저장되고 화면에는 다시 보이지 않습니다 |
| 프로세스 | match | `ps` 명령줄에 대한 정규식. 다른 프로세스와 겹치지 않게 구체적으로 적습니다 (예: `java .*shelter\.jar`) |
| 프로세스 | 로그 파일 · 시작 스크립트 | 셸 특수문자가 없는 절대 경로. 시작 스크립트는 인자 없이, 스크립트가 있는 폴더에서 실행합니다 |

> 이 화면에는 로그인이 없습니다. 접속할 수 있는 사람은 누구나 프로세스를 중지 · 시작하고 설정을 바꿀 수 있으므로, 내부망에서만 열어 두세요.
