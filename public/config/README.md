# debug-live-state

여러 백엔드의 디버그 상태 API(`GET`)를 주기적으로 호출해서, 응답 JSON 전체를 한 화면에서 실시간으로 보여주는 대시보드입니다.

## 사용 방법

- **상태 확인**: 왼쪽 사이드바에서 엔드포인트별 상태를 한눈에 볼 수 있습니다. 초록은 정상, 빨강은 오류, 회색은 첫 응답을 기다리는 중입니다. 항목을 누르면 해당 카드로 이동합니다.
- **검색**: 상단 검색창에 key 나 value 를 입력하면 일치하는 카드만 남고, JSON 에서 일치하는 부분이 강조됩니다.
- **카드 버튼**: `↻` 는 지금 바로 새로고침, `⏸` 는 이 카드의 폴링을 일시정지합니다.
- **설정 변경**: `⚙ 설정` 에서 엔드포인트를 추가·수정·삭제하고 순서를 바꾼 뒤 **저장**하면 바로 반영됩니다.
- **설정 백업**: `⚙ 설정` 의 **내보내기**로 설정 파일(`endpoints.json`)을 받고, **가져오기**로 다시 불러올 수 있습니다.

## 설정 항목

| 항목 | 필수 | 설명 |
|---|---|---|
| id | O | 엔드포인트를 구분하는 고유 이름 |
| 그룹 | | 같은 이름끼리 묶어서 보여줍니다 (컨테이너 · 프로젝트 단위) |
| 표시 이름 | | 카드에 보이는 이름 (비우면 id) |
| URL | O | `http://` 또는 `https://` 로 시작하는 GET 주소 |
| 주기(ms) | | 폴링 주기 (비우면 기본 폴링 주기) |

> 카드에 `network error` 가 보이면 대상 서버가 꺼져 있거나, 이 사이트에 대해 CORS 를 허용하지 않은 경우입니다.
